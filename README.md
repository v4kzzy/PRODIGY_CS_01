# Caesar Cipher GUI 🏛️

A sleek and modern graphical application for encrypting and decrypting text using the classic Caesar Cipher algorithm. Built with Python and `ttkbootstrap`, this tool offers a user-friendly dark-themed interface for real-time cryptography.

## ✨ Features

- **Live Encryption:** Text updates instantly as you type or adjust the shift value.
- **Modern Interface:** Designed with a professional dark theme using `ttkbootstrap`.
- **Brute Force Mode:** Includes a "Try All Shifts" button to automatically generate all 25 possible outcomes for unknown ciphertexts.
- **Smart Clipboard:** Quickly copy results with a single click.
- **Input Validation:** Automatically handles non-alphabetic characters by leaving them unchanged.

## 🛠️ Built With

- **Python 3.x**
- **Tkinter** (Standard GUI library)
- **ttkbootstrap** (Modern styling wrapper)
