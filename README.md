A sleek and modern GUI application for encrypting and decrypting text using the classic Caesar Cipher technique. Features live encryption, the ability to try all shifts, and a dark-themed, modern interface built with Python’s Tkinter and ttkbootstrap
Features
	•	Live Encryption: Automatically updates output as you type.
	•	Custom Shift Value: Easily set the shift value for encryption/decryption.
	•	Try All Shifts: Quickly see decrypted results for all 26 shifts.
	•	Clear Button: Reset input and output fields instantly.
	•	Modern Dark UI: Designed with ttkbootstrap for a clean, professional look.
	•	Error Handling: Provides clear messages if shift input is invalid
